# TkxModal — docs

`TkxModal` is a centred, focus-trapped dialog for decisions that must
block the page: confirming a destructive action, a short form that cannot
be abandoned half-way, or a message the user must acknowledge. Reach for
it only when interrupting the user is the point. For secondary workflows
that run alongside the page (filters, detail panes, settings) use
`TkxDrawer`; for passive feedback use `TkxToast`. It requires a `title`
(used as the dialog's accessible name), returns focus to the trigger on
close, and supports `sm` / `md` / `lg` / `full` sizes plus an optional
`footer` slot for action buttons.

## Key props

| Prop | Use |
|---|---|
| `isOpen` / `onClose` | Fully controlled — you own the open state |
| `size` | `sm`, `md`, `lg`, `full` |
| `closeOnOverlayClick` / `closeOnEscape` | Turn off for forms with unsaved input |
| `footer` | Action row; keep the primary action right-most |
